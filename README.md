DompetKeluarga — Perencana Anggaran Rumah Tangga Indonesia. Kalkulator interaktif (penghasilan, 8 pos pengeluaran, mode hemat, grafik alokasi SVG, vonis 50/30/20 yang disesuaikan, hitung mundur dana darurat), contoh anggaran nyata dari upah minimum resmi 2026 (UMP DKI Jakarta Rp5.729.876 · UMK Kota Bekasi Rp5.999.443 · UMK Kab. Bekasi Rp5.938.885), aturan 50/30/20 yang digeser menurut tingkat gaji, dan helper tarif listrik PLN (R-1 1.300 VA, Rp1.444,70/kWh, Q4 2026). Semua angka riil berlabel sumber dan periode di halaman Data & sumber; semua hitungan jalan di browser, tanpa jaringan. Plain static files — no build step, nothing loaded over the network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or just open `app/index.html` in a browser.
